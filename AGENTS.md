# Family Atlas Desktop

- Tauri 2 desktop app: Rust + bundled SQLite; static ES modules. No Python, HTTP listeners, sidecars, dev server, CDN, telemetry or remote family-data requests.
- `cargo run --manifest-path src-tauri/Cargo.toml` embeds local web assets even in development. `npm run build` creates native platform bundles. Windows/macOS/Linux builds require each platform's Tauri prerequisites.
- `cargo test --manifest-path src-tauri/Cargo.toml` and `node --test tests/*.test.mjs`. Tests must use temporary stores, not real app data or migration copies.
- `src-tauri/src/domain.rs` owns validation/editing, `gedcom.rs` interchange, `store.rs` compatible schema-v1 SQLite + revision conflicts + backups. Native commands in `commands.rs` expose specific actions, never unrestricted filesystem operations. Reserve archival IDs when creating people so a deleted person is never confused with a new person in an interchange overlay.
- Data live under the OS app-data directory, never bundled. Local migration copies, photos, research and backups are private and ignored; never commit or upload them. Do not modify a separate legacy project while working here.
- Preserve IDs, arbitrary fields, citations, archival extensions, contradictory dates, exact date text and unknown service years. Native JSON format remains family-atlas v1, compatible with the stable Python edition.
- Local photos only, validated raster signatures, content-hash names; reject traversal/symlinks. Never upload family data. Import is validated and revisioned; native export dialogs grant the destination, not arbitrary renderer paths.
- Photo editor is non-destructive: `cropPhoto` writes optional per-person `photoCrops[originalReference]` with normalized rectangles for `tree`, `poster`, `posterPair`, plus optional `portraitPhoto`. Validate finite in-bounds coordinates and ownership; never rewrite originals or reorder source photo links. Keep metadata on unrelated person edits and in JSON/SQLite. GEDCOM does not carry it. Use shared `web/photo-crop.mjs` frame geometry and `photo-render.mjs` in tree, editor previews and poster embedding; the same photo can have different crops for different people. Test `tests/photo-crop.test.mjs`, `src-tauri/src/crop_tests.rs` and real WebView crop/pixel/cancel checks on temporary data. Keep serde_json float_roundtrip enabled for exact persistence of fractional coordinates.
- Preserve existing layout, Russian calendar, per-person era backgrounds and date-free SVG/PNG posters. Artwork must whitelist names/portraits/connections, never dates, notes or places.
- Poster preview/export must embed the full original user PNG (same source as canvas background), not a URL, icon crop or old night-sky gradient. `get_poster_background` resolves only that packaged public asset; SVG embeds original bytes, PNG rasterizes the same SVG. Keep exports disabled if background loading fails. Icons derive from the left square of this image; see `artwork/README.md`. Desktop shortcut script must not overwrite the legacy GEDCOM shortcut or unrelated applications.
- Source code uses MIT; background/derived icon exceptions are in NOTICE.md. Publication checks: `npm run check:publication` and `node scripts/check-publication.mjs --history`. Never use real family screenshots in documentation. `scripts/prepare-public-folder.mjs` makes a new source-only repository without local history; it must not overwrite existing folders or copy symlinks/private data. Publishing remains an explicit user action.

# Иконка из пользовательского фона

Исходник — неизменённый PNG 5504×3072:
`web/images/nano-banana-4k-6aee231e41f09db7edd3a148.png`.

`app-icon.png` — квадрат 1024×1024, полученный из левой квадратной области
исходника (ствол, крона и корни), без растяжения пропорций. Центральная обрезка
оставила бы преимущественно пустой фон, поэтому выбран участок с самим деревом.

Повторное создание на Windows:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/make-app-icon.ps1
npx tauri icon artwork/app-icon.png
Copy-Item src-tauri/icons/128x128.png web/app-icon.png
```

Tauri генерирует размеры ICO/ICNS/PNG для нативных значков и установщиков.
Плакат использует **полный исходный PNG**, а не квадратную иконку, и встраивает
оригинальные байты в SVG. В PNG-выгрузке этот же фон растеризуется вместе с плакатом.

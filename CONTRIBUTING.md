# Участие в проекте

Спасибо за помощь «Семейному атласу»!

## Сообщить об ошибке

Укажите ОС, версию приложения, последовательность действий, ожидаемый результат
и фактическую ошибку. Если возможно, воспроизведите проблему на вымышленном дереве.

**Не прикладывайте** настоящие SQLite-базы, фотографии, GEDCOM/JSON-экспорты,
резервные копии и скриншоты с данными родственников. Замените имена, даты и лица
на синтетические примеры; удалите локальные пути и секреты из журналов.

## Изменения кода

1. Создайте fork и отдельную ветку.
2. Следуйте [README](README.md) и [AGENTS.md](AGENTS.md).
3. Не добавляйте Python/HTTP-сервер в runtime и не загружайте семейные данные в сеть.
4. Сохраняйте неизвестные поля, цитирования, точность дат и оригиналы фотографий.
5. Покройте изменения синтетическими тестами. Тесты должны использовать временные
   каталоги, а не текущую базу приложения.
6. Запустите:

```bash
npm ci
npm test
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo test --locked --manifest-path src-tauri/Cargo.toml
npm run check:publication
```

В PR опишите цель, изменения и выполненные проверки. Не меняйте несвязанные файлы.
Не прилагайте `target/`, установщики, `node_modules/` или пользовательские данные.

Отправляя собственный код, вы предлагаете включить его под MIT-лицензией проекта.
На чужой код, изображения и шрифты нужны соответствующие разрешения и уведомления;
смотрите [NOTICE.md](NOTICE.md).
